# 作り方の9つの決まり

「動く」だけのモデルと、VTube Studio で崩れずに持ちこたえるモデルとの差を生んだもの。
キャラのどのパーツを変える前にも、これを読む。

1. **静止時 = 元絵そのものの px。** 静止時は、すべての px が絵のもの。作るのは隠れた部分だけ。
   静止ポーズを元絵と比べて確かめる。人物全体でも、レイヤーごとにも。
2. **隠れた部分は描く。ぼかさない。** 動きでめくれて見えるもの（前髪の下のおでこ、横髪の下の耳、あごの下の首）は、
   画像生成の「X を消した」下絵から取り、隠れている所にだけ使う。なめらかな塗りは、見える所に動いてきた瞬間に、
   にじみに見える。元絵の見えている部分と食い違う下絵の線は捨てる。
3. **境目は切らずに、混ざった色を分ける。** 2つのパーツの間の線は、手前のパーツのもの。奥のパーツは、
   その線の下まで混じりけのない色で続く。
4. **持ち主は剥がして調べる。** px を直す前に、
   そのポーズでアートメッシュを1つずつ単独で描き（`preview.py <project> peel`）、どれがそこを描いているかを見る。
   合成した絵から持ち主を推測したら、3回続けて外れた。
5. **段階は決まった順に、それぞれ入力の控えから。** 最初から全部走らせても、
   少しずつ進めた状態が再現されなければならない。レイヤーを分ける段階は、
   そのレイヤーを編集するすべての段階のあとに走らせる。
6. **動きは見本の向き絵と比べる。** キャラを、30度向いた姿と見上げ・見下ろしで描き直してもらい（`imagegen.py ref`）、
   同じ角度のモデルをそれと比べて測る：位置と大きさ。顔の内側は元絵の比率を保つ。塊（髪の輪郭）は見本の絵に従う。
7. **見る大きさで、動かして判断する。** 物理演算込みの首振り（`motion_strip.py`）、まばたきは1コマずつ（`--blink`）、
   暗い地の上で、VTube Studio に映る大きさで。数値や静止画の一覧は、動かせば明らかに崩れているモデルを通してしまった。
   2〜8倍の拡大は、細かい点を探すときだけ。
8. **物理演算は毎秒30ステップと60ステップで**（`phys_check.py`）：VTube Studio は、
   描画1フレームごとに物理演算を1回進める。
9. **変更のたびに、インストール済みの版と前後を比べる。** 「悪化」ならすぐ戻す。危ない変更は新しい別版に入れる。

パーツごとに1行で：
- **前髪**：色分け図の下絵（束ごとに別の色）で髪の束に分け、束ごとに独立して揺らす。横髪は顔の手前に置き、
  首を回すと顔の縁の奥行きを取る。
- **耳と頭の側面**：覆っている束だけを消した寄りの絵から。
- **目**：上のまつ毛全体を1本の閉じ線に写し、その線はまぶたが合わさる所に据える。開いた目のものは、
  顔のレイヤーに何も残さない。目の上にある目の線（まつ毛の先、アクセント）は、目と一緒に閉じる。
- **口**：元絵そのものの線をリボンにして、どの母音の形にも曲げる。口の中、歯、舌つき。
- **首**：顔の裏まで伸ばす。見上げでは広げ、あごの下にやわらかい影。
- **切り替え**（星の目、衣装）：0.5 で入れ替え、クロスフェードは決してしない。
