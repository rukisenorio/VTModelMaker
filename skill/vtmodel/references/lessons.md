# 近道：本体（どんな絵からでも、約1時間で最初に動くモデル）

**本体が作るのは粗い最初のモデルで、仕上がったモデルではない。動かして判断する。** 2026-10-22、
本体で作った3体のモデル（chara4、chara5、chara6）は、どの数値チェック（穴、静止時の差、check ok）も、
どのポーズの一覧も通っていた。ユーザーはそれを VTube Studio で見て「全部雑です、何をやってるんですか」と言った。

見る大きさで動かすと、こう見えた：
- 髪の縁がほつれ、切れる。
- 顔の横で暗いかけらがちらつく。
- リボンがばらばらになる。
- 首を回すと、顔の横ににじみとひびが出る。
- 髪が1枚の板のように引き伸ばされる。

何かを「できた」と言う前に、`scripts/motion_strip.py <build> <out> --compare <previous build>` を実行する。
モデル自身の物理演算を毎秒30ステップで回した首振りを、見る大きさのコマで暗い地の上に、前と後で並べて作る。それを見る。
そのうえで、最初のキャラたち（chara3 など）の方法でパーツごとに作り直す：
- まず見本の向き絵。
- 髪を髪の束に分け、束ごとに描いた隠れた部分と、自分の揺れを持たせる。
- 帽子、飾り、目、口のマスクを確かめる。
- 変えたパーツごとに、前の組み立てと比べた動きの確認画像。

動かして何かがまだ崩れるうちは、何も VTube Studio に入れない。

`kit/` は **キャラごとのコードを持たない** 汎用の流れ。絵に固有のものは、すべてプロジェクトの
`character.json` にある：
- ガイドの格子から読み取った、約25か所の位置合わせの点。
- 一覧の絵から選んだ囲まれた背景。
- 画像生成の指示に使う、1段落の説明。

これが作る VTube Studio のモデルには、次がある：
- 首振り、うなずき、傾き。
- 描いた閉じ目と、笑った閉じ目へのまばたき。
- 視線。
- 眉。
- 絵そのものの線を曲げて作る口。母音（あ・い・う・え・お）、口の中、歯、舌つき。
- 振り子で揺れる前髪、後ろ髪、横髪。
- 体の傾き・ひねり・呼吸と、肩から揺れる腕。
- ホットキーで9つの表情。
- トラッキング（母音とマイクの音量も）。

新しい絵には、どれもまずこれを使う。まだできないことは最後に挙げた。
それらのパーツはテンプレートの手順（`new-picture.md`）で、キャラ専用の本体の写しの中で作る。

見たことのない絵での試験（2026-10-21。どちらも試験のために Codex が描いた）：
- **t1**：全身、茶色の長い髪、セーラー服、白い背景。パソコンの処理時間で約1時間で組み立てて確かめた。
- **t2**：腰から上、色白の肌に短い銀髪、両目にかかる前髪、パーカー、灰色の背景。組み立てて確かめた：首振り、うなずき、
  どの開き具合でのまばたき、視線、口が、バストアップの大きさできれいに見える。
そのあと別のセッションが両方を読み取り専用で2回確認し、崩れの場所ごとに、
そこを覆っているものをアートメッシュ単位で数えた。直し方は下にある。2回目のあとに残ったもの：
後ろ髪と前髪の毛先が一緒に振り切れたときの、こめかみの小さな切れ目。髪の毛の上に描かれたまつ毛の先が、
目を閉じても残る（閉じ線の外にある）。上げた首の陰影が平ら。
どちらも setup から package 済みのモデルまで、パソコンの処理時間で約1時間（plates 約5分、
segment 約3分、build 約1分）。

## 手順（コマンドはどこからでも実行できる。`$K` = 本体、`$P` = プロジェクトのフォルダ）

プロジェクトのフォルダはユーザーが選んだ場所にする。セッションの作業用フォルダには決してしない。

1. `python3 $K/setup.py $P <Name> <picture>` が作るもの：
   - `src/art.png`。
   - 位置合わせの点の名前と、それぞれの意味を書いた `character.json`。
   - `work/guide_full.png` と `work/guide_head.png`（番号付きの格子、元画像の px）。
   - **キャラ専用の本体の写し**（`$P/kit/`）と、2倍拡大のネットワーク。

   以後は `$P/kit/...` を実行する。1キャラのための変更はその写しに入れる。本体を変えるのは、どの絵にも役立つことだけ。
2. `character.json` を埋める：
   - **`points`**：元画像の px で `[x, y]`、隠れた点は null。2枚のガイドから読み取る。
     L は見る人から見て左。必要なもの：
     - 頭：`crown`（髪の下の頭蓋）、`chin`、目の高さでの `face_l` と `face_r`、`eye_l`、`eye_r`、`mouth`、
       `brow_l`、`brow_r`、`nose`。
     - `hair_top` と `hair_bottom`（いちばん下の毛先。短い髪なら null）。
     - `neck`。
     - 体：`shoulder_*`、`elbow_*`、`wrist_*`、`hip`、`knee_*`、`foot_*`。腰から上の絵では、絵の外にある点は null。
   - **`describe`**：`character`、`hair`、`eyes`、`skin`、`outfit` を平易な英語で。
     下絵の指示はこれから組み立てるので、色と髪の部位（前髪 bangs、横髪 side locks、三つ編み braid）を名指しする。
3. `python3 $P/kit/run.py $P --to prep` を実行し、次を見る：
   - `work/figure_look.png`：暗い地と緑の地の上の切り抜き。
   - `work/pockets_sheet.png`：囲まれた背景色のかけらすべてに、色を付け番号を振ったもの。
     髪の毛の間や腕と体の間の背景は背景。白い服、白目、ハイライトは背景ではない。
   - 背景のものを `character.json` に `"bg_pockets": [[x, y], ...]` として入れ（各かけらの `work/pockets.json` での
     `point`）、もう一度 `--to prep` を実行する。
4. `python3 $P/kit/run.py $P --from plates`。Codex の下絵10枚を作り（約6分、2枚ずつ同時に）、続いて segment、eyes、
   face_parts、build、package、preview を走らせる。
   - `work/plates_look*` か、下絵そのもの（`gen/in/<n>_in.png` と `gen/out/<n>.png` を並べて）を見る。
   - 次に `preview/poses.png` を見る：暗い地の上に、バストアップの大きさで24ポーズ。
   - `preview.py $P rest` は静止ポーズを絵と比べる：0.25倍で差が40を超える px が約3000あるのは普通（縁）。
   - `preview/holes.png` と `holes` の行：頭と髪を組み合わせた81ポーズで、静止時と比べて透ける所。
     最悪の3つをマゼンタで塗る。絵そのものの囲まれた背景は髪と一緒に動くので、絵を見て判断する。
     次に CHECK の行（segment のものと preview のもの）：体には頭のものが何もないこと。
5. `python3 $P/kit/package.py $P --install` でインストールする。インストールするのは、VTube Studio
   が閉じているときだけ。既存の設定ファイルに合わせ込み、インストール済みの写しを控えておく。

下絵を1枚作り直すには：`gen/out/<n>.png` をよそへ移して `run.py $P --from plates`。指示や箱を変えるには：
`character.json` の `"plates": {"<n>": {"prompt": ..., "box": [x0, y0, x1, y1]}}`（キャンバス px）。`"skip": true`
でその下絵をやめ、新しい名前に箱と指示を付ければ1枚足せる。

## 何かがおかしく見えるとき（t1 と t2 の試験でわかったこと）

まず剥がして見る：その場所を、アートメッシュを1つずつ単独で描く。崩れの多くは、リグではなく持ち主の問題だった：
- **首振りやうなずきで、あごの横に黒い切り欠き。** 顔の下部の裏に何も描かれていなかった。顔は上へ、後ろ髪は下へ動く。
  後ろ髪の隠れた部分を、顔の下部の裏まで続けなければならない。
- **髪の上を滑る白っぽい縁。** 顔の領域が、輪郭線の外の明るい px まで取っていた。広げるのは暗い px だけにする。
- **首を回すと、耳の色の切れ端が取り残される。** 隠れた耳の細い切れ端が体にラベル付けされ、体の延長（run-on）
  がそれを広げた。頭の見えているかけらは、すべて顔のもの。
- **白っぽくなった塗り。** 色調合わせには、空の塗りの配列ではなく下絵を渡さなければならない。
- **髪と一緒に動く白い点。** 髪のマスクのクロージングが、髪の毛の間の白い服を取り込んでいた。足すのは、
  髪の色のものだけにする。
- **静止時に、隠れた塗りが見える。** 隠れた部分は、静止時にそれより「手前」にあるパーツの下にだけ置く。
- **顔が髪を取った（色白の肌に銀や白の髪、t2）。** 色の距離では、髪は bald の下絵の頭皮と「違わなかった」。
  肌は暖かさ（R − B）で、この絵の肌を基準に、片側だけで見分ける：肌より `WARM_TOL`（max(5, 0.45 × 肌の暖かさ)）
  以上冷たいものは肌ではない。色白の肌は、銀髪より15ほどしか暖かくない。固定の許容値25では、髪の半分が顔に入った。
- **髪が揺れると、目に暗い跡（目にかかる前髪、t2）。** 目のレイヤーは髪の毛の下に穴があり、
  白いかけらは目の中央にいちばん近いものしか残していなかった。今は髪の下の目を `eyes_clear` が描き、
  目の中の白いかけらはすべて残す。その髪の下の顔には、bald の下絵の目（まばたきのときに目の幽霊になる）
  ではなく、ただの肌を入れる。
- **顔にかかる髪の毛が、顔に残った。** 頭の中では、肌でも目鼻でもなく、
  bald の下絵と少しでも違うものは髪（しきい値を下げて18）。
- **細い遊び毛が、弧のように取り残される。** 肩より上で bald の下絵が背景を見せる所では、
  髪の塊から 1 HR までの人物の部分は髪。
- **上げたあごの下に白っぽい帯。** 首の隠れた部分の高さが 0.6 HR だったが、面長の顔はあごがもっと上がる。
  今は列ごとに、うなずきの形そのもの（下絵の奥行きで32度）から大きさを決める。
- **巨大な moc3（アートメッシュ31個で 106 MB）。** 首振りの格子に軸を2つ載せると、
  キーフォームが掛け算で増える（3^6 通り）。追加の動き（横髪の上下の弾み）は、同じ箱と格子を持つ子の格子に置く。
  そうするとファイルは約 14 MB。後ろ髪を前髪に、首振りだけ（揺れではなく）つなぐと 7〜9 MB になった。

別のセッションによる t1/t2 の読み取り専用の確認から（崩れの場所ごとに、
そこを覆っているものをアートメッシュ単位で数えた）：
- **首を回すたびに、頬の裏に明るい板（首）。** 首の隠れた部分が、目の高さまで、顔と同じ幅で入っていた。
  今は首そのものの幅（あごに向かって +0.12 HR）で、列ごとに上のあごが上がりうる所まで、影の色調で入れる。幅と上端は、
  あごの下の行から取る。前は、あごの横にはぐれた影の肌の帯がそれを決めていた。
- **あごの影が、暗い縁のある白っぽい帯として取り残される。** その影の肌が体になっていた。今は、
  暗くても同じくらい暖かい肌を首が取る。
- **目の横に浮いた暗い線、眉がばらける。** bald の下絵は目鼻を丸ごと描く。髪の下に隠れたその線（横髪の下のまつ毛の先、
  前髪の下の眉の端）は目鼻のもの（feature_masks.npz の `<name>_hidden`）で、そこの顔には肌を入れる。
- **前髪が揺れると、こめかみに背景が見える。** 後ろ髪が、前髪の揺れにもつながっていた。今は、
  切れ目の近くでは前髪と一緒に回るが、揺れは自分の振り子で揺れる。
- **頭頂の髪の毛が体に残った。** 下絵の信用しない余白が、箱がキャンバスの端に接する所にも掛かっていた。
- **上げたあごの横に灰色のにじみ。** 顔の下部の裏の後ろ髪は、`nape` の下絵が描く（2体目のキャラの nape の下絵）。
  それがない所にだけ、暗めのなめらかな塗りを入れる。

2回目の確認（2026-10-22、同じ方法）。どれも汎用の形で直した：
- **首を回すたびに、あごの横に真っ白な部分。** 首の裏の体の隠れた部分は、headless の下絵から取る。この下絵は、
  頭と首のあった所に背景を描く。その背景の塗り広げを首の裏の帯の中だけでしていて、
  そこには塗り広げを始める外側の背景がなかった。今は下絵の背景を下絵全体で塗り広げ、そのあとで帯に切る。
  （白い服は残る：輪郭線で囲まれているから。）
- **後ろ髪が揺れると、こめかみに穴。** 顔から 0.4 HR 以内の後ろ髪（こめかみと耳の上の根元）は、5分の1しか揺らさない。
  自由な毛先は存分に揺れる。
- **首を回すとあごの線が二重、上げたあごの下に浮いた線。** あごの輪郭線が前髪に入っていた：bald の下絵はそれを数 px
  ずらして、あるいは細く描き直すので「違う」とされた。あごと、目より下の頬のまわりでは、下絵も 2.5 k px
  以内に描いている暗い線（下絵の中で明るいものの横にある暗いもの）は顔のもの。それより上では、
  下絵の線は髪の下にある髪のない頭の線なので、この決まりは目の下で止める。
- **上げた首を横切る白っぽいぎざぎざの継ぎ目。次に縦縞。** 首の上端より上の隠れた部分は、今は首の上端の色から始め、
  首に沿ってならし（列ごとだと筋になった）、0.08 HR 以内で暗くしていく。明るくはしない。
- **髪の毛の上に灰色のかけらが残る（髪の上に描かれたまつ毛の先）。** 髪で切り離された顔の小さなかけらで、
  肌ではなく暗いか冷たいもの、目か眉から 0.12 HR 以内のものは、その目や眉のもの。髪の下に隠れた線は、
  触れているときだけでなく、0.06 HR 以内に来ていれば、その目鼻のもの。
- **襟のかけらが、髪と一緒に動く。** 髪飾りの決まり（髪に接するかけらは髪へ）が、髪の毛の間から見える襟を取っていた。
  飾りとは、bald の下絵も消したもの。下絵が残すものは、髪の後ろの服。
- **うなずくと、後ろ髪に紺やフードの灰色の板。** backhair と nape の下絵は、頭の後ろの襟やフードも描く。
  そして暗い服は、髪の暗い輪郭線の色に近い。後ろ髪の塗りには、服の色より髪の色に近い色だけを使う。
- **うなずくと、首の横に髪の色の板（短い髪）。** 後ろ髪を首の裏で、あごの 0.9 HR 下まで続けていた。今は列ごとに、
  nape の下絵の髪が終わる所で止める。

3回目の確認（2026-10-22）。別のセッションが、人物に囲まれて透けている px を81ポーズで数えた：首振りとうなずきに、
後ろ髪と前髪の揺れ -1/0/1 を掛け合わせ、0.25倍で、静止時と比べた。この数え方が、今の preview の段階の `holes`
チェック（`preview/holes.png`）。
- **うなずくと長い髪が肩から浮く：両肩の上に背景の帯。** 髪の首振りとうなずきは、
  あごのずっと下でようやく弱まっていたので、襟の上の髪がまだうなずきの 90 % を受けていた。今は、
  髪は体の上に乗る所で頭から離れる：列ごとに、体の上端の 0.15 HR 上から 0.35 HR かけて、15 % まで。一般には、
  あごの 0.2 HR 下から肩の 0.3 HR 下までで離れる。t1 では、下へのうなずきで +860 から +218 になった。

## 本体で作ったモデルの第2段階：「もっと頑張って」のあとに chara4 が得たもの（2026-10-22）

効果のあった順番。汎用の道具は、今は本体に入っている：
1. **まず見本の向き絵。** このキャラ用に書いた指示で `imagegen.py ref`（左右に30度向く、あごを上下に30度、
   どの指示にもデザイン全体を書く）。それぞれを同じ角度のモデルの横に、襟で位置をそろえて（下3分の1で
   SIFT）、同じ切り取りで並べる。
   - chara4 の首振りは、顔を見本の半分しか動かしていなかった。直し方は `"rig": {"yaw_amp": 1.3}`（既定 0.82）：
     顔の首振りの面の奥行き。
   - 見上げで、顔の上がり方が足りなかった。直し方は `"nod_up_scale": 1.6`。
2. **見上げ：首。**
   - 高い襟の下では、首は襟の影の中のわずかな部分で、その暗い色調が茶色の塊を作った。`"neck_tone": "lit"` で、
     隠れた首を光の当たった肌にする。
   - `"chin_shade": true` で、あごが落とす影を足す：顔のワープの上で、あごの線の下にアニメ塗りの帯。首でマスクし、
     ParamAngleY に合わせてフェードインする。下から見た見本の向き絵に描かれているのが、これ。
   - あご自体の輪郭線が、首にラベル付けされていた。今は segment がそれを顔に渡す。
3. **肌と同じ色の髪：** 下絵 `hairmask`（髪全体を平らな緑で塗ったもの）は、今は本体の下絵の表にある。
   segment はその緑を髪に加える：chara4 では、顔になっていた髪の毛の内側 232,000 px がそうだった。
4. **本体が分けないパーツ** は、`$P/kit/` の中のキャラごとの段階として、segment のあとに走らせる（`run.py` の
   STAGES）。例は `kit/examples/chara4/` にある。
   - `hat_split.py`、花と房飾りのついたベレー帽：
     - ドーム部分と花に SAM-HQ の点。
     - `nohat` の下絵が、ベレー帽の下の髪を描く。その髪を、ベレー帽の見えている布の上には決して置かない。
     - ベレー帽はすべての髪の「後ろ」に置く（z -1）：横髪はそのフラップの前に垂れる。布は、近くの髪の下まで続ける。
     - 花は中心のまわりに回る。房飾りは垂れて揺れる。
   - `earring_split.py`：手で描いた多角形と色。その下は、それらの px を持っていたレイヤーに inpaint で埋める。
     顔のワープの上で耳から下がり、奥側ではフェードアウトする。
   - `coat_split.py`、長いコートの裾：
     - Codex の下絵 `coatmaskL/R` は「1つの」パーツを平らな黄色で塗る。パーツの各部分を名指しした指示なら、
       全部が塗られる。縁は、その下絵との差で決める。
     - 黄色の隣にある細い線で、大きな塊の一部でないもの（裾自身の輪郭線と縁取り）は一緒に移す。
     - 脚の裏の隠れた帯は、裾が脚に触れる所から、脚の中だけを通して広げる。
       自由に広げると背景を横切り、ひれのように見えた。
     - 裾は、脚の裏では揺れを小さくする（`*_frontdist.npy`）。房飾りは玉から下がる。
     - やり直しのときは、体の見えている px を、古いレイヤーからではなく必ず絵から戻す：
       レイヤーの隠れた帯を戻したら、脚が赤く塗られた。

5. **揺れるパーツは、すべて `phys_check.py $P` で確かめる。** 頭と体を動かしたときと静止時（待機の風）について、
   物理演算の各出力の幅を、毎秒30ステップと60ステップで出す。chara4 では、どの出力も動きの中で 0.4〜0.7、
   静止時に 0.3〜0.4 揺れ、振り切れたものはなかった。
6. **見るための道具**（セッションを再起動しても残るもの。scratchpad は残らない）：
   `preview.py $P zoom <box> "<pose>;..."` と
   `preview.py $P peel <box> "<pose>"`（その箱を塗るアートメッシュすべてを、1つずつ単独で）。
7. **揺れない髪（今は本体の段階で、segment のあとの `hair_base`）。**
   - 髪そのものの色を使った、やわらかく暗めの写しを、すべての髪の下に置く（z -2）。首振りには乗るが、
     揺れはまったくない。揺れる髪の束がめくって見せるのは、背景ではなく影の中の髪になる。
     見えている髪の完全に下にあるので、静止ポーズは変わらない。
   - 同じ段階で、後ろ髪の隠れた部分のうち見えている髪より暖かい所には、髪の影の色を入れる。顔の隣の下絵の塗りが、
     顔の影になった縁を髪と取り違えていた：首を回すと、あごの横に藤色のにじみ。
   - 81ポーズでのすき間チェック：chara4 の最悪は +1385 → +887。t1：静止時より悪いポーズが 23 → 6、最悪 +252 → +204。
     t2：18 → 7 ポーズ、最悪 +1136 → +773。
   - chara4 でまだ数に出るのは、横髪と襟のフラップの間にある、絵そのものの囲まれた背景（`bg_pockets`）。
     静止時にもあり、首を回すと閉じる。
   - 本体がスクリプトとして走らせる段階は、どれも `C.open_project()` のあとで layerio を import する：
     layerio はそこからレイヤーのフォルダを見つける。先頭で import していたときは、本体（写しではなく）
     がプロジェクトを直接走らせると、本体自身のフォルダに書き込んでいた。
8. **消した下絵で、垂れ下がる飾りを分ける**（chara4 の `pendant_split.py`：リボンタイ、胸の鎖、腰の鎖）。
   - グループごとに Codex の下絵1枚、「X を消し、後ろにあるものを描く」。
   - パーツは、絵が下絵と違う所。位置ずれに強い差（`crop_diff`）で測る。そのままの差だと、
     下絵が数 px ずらして描き直した縁（襟の折り返し、ボタン、短パンの縁取り）を全部拾い、それらが一緒に揺れた。
   - はっきりした芯（D > 50）、その中の少しだけ違う穴（パーツの影になった中央。輪の内側は決して入れない）、
     隣の小さく弱いかけら（玉）。そのうえで、つながった構造だけを残す。
   - 下絵の絵は、絵の色調に合わせて後ろのレイヤーに入れる。
   - やり直しのときは、最初の実行の前に保存したラベル図（`labels_before_pendants.png`）から戻す。
     いちばん近いラベルからは決して戻さない：袖の上にある鎖が腕に入り、揺れなくなった。

     `phys_check.py` で確かめる（約 0.3 動くまで、先端の出力の scale を上げる）。

## 束ごとに作り直した髪と、各束がめくって見せるもの（chara4、2026-10-22 の夜、「全部雑です」のあと）

**まず見る：前髪を「抜いた」静止ポーズ。** `hair_front` と `lock_*` のアートメッシュを外してモデルを描く（レンダラの
`skip=`）。それが、どの束でも揺れたときにめくって見せるもの。chara4 ではこう見えた：
- 前髪の下は、肌の四角と灰色の塊のつぎはぎ。
- 耳がまったくない。
- 横髪が顔の「後ろ」にある（後ろ髪）：首を回すと頬がその上を滑り、横髪の下には何もなかった。

直したもの、段階の順に：
1. **横髪は専用の下絵で。** lockmap は前髪しか塗らない。下絵をあと3枚：
   - `sidemap`：横髪それぞれ（頬の横、耳の上、外に跳ねるもの）を別々の色で、残りは灰色。
   - `nosideL` / `nosideR`：左右それぞれの寄りの絵で、横髪だけを取り去ったもの。Codex は耳全体、こめかみ、
     耳の後ろの後ろ髪（暗めに）を描く。
   segment の `side_locks()` は、sidemap の色を種にして、灰色の髪に前髪と同じ watershed をもう一度かける。
   noside の下絵が取り去った px は、すべていちばん近い横髪へ。灰色のままだと耳の後ろの後ろ髪になり、
   耳をそのまわりで切り抜かなければならなかった。
2. **watershed は、髪そのものの上だけでかける**（`hairmask` の下絵の緑）。
   bald の下絵が髪と一緒に取り去ったベレー帽は、その段階では髪。自分の種がないと、
   フラップと房飾りがいちばん近い束から塗り広げられ、髪として揺れた。
3. **髪の上の束の色は、絵が同じ色の所でも数える。** 赤い筋の入った束は、絵の赤の上に赤で塗られていた。
   色分け図が絵と違うことを条件にすると種がなくなり、後ろ髪のままになった。
4. **下絵そのものの髪のマスク**（下絵の「上で」作る下絵：character.json の `"on": "<plate>"`、または本体の表にある、
   backhair の上の `bh_hairmask`、noside の下絵の上の `ns_hairmaskL/R`）。
   色白の肌とピンクがかった銀髪は同じ色（赤から青を引いた値が、肌の17に対して16）で、
   前髪の下の生え際は閉じた線ではない。色で探すと、頭頂が顔になり（顔のレイヤーの中に、かき上げた髪）、
   noside の箱がそれをまっすぐ切った。
5. **前髪の下の顔の隠れた部分は、backhair の下絵そのものの絵**。その生え際（そのマスク）まで。
   後ろ髪の隠れた部分はその先の同じ下絵で、顔の縁の下へ 0.1 HR 続ける：顔は自分の面の上で、
   髪は頭の面の上で回るので、生え際が数 px ずれる。
6. **横髪の下の頭の側面（こめかみ、耳の前の肌、耳）は、顔のレイヤーに入れる**。noside の下絵から：
   その髪のマスクが髪ではないとするもののうち、背景でも服でもなく、頭の肌から 0.5 HR 以内で、眉の上から口までのもの。
   肌の色で取ると、耳のピンクがかった内側の px が、1つおきに抜けていた。bald の下絵の耳は低く外側にずれていたので、
   そこでは使わない。（`ear_split.py` は、エルフ耳のように自分で動かなければならない耳のために残してある。）
7. **前髪を束に切り分けたら、前髪の暗い写しを後ろ髪にしない**：揺れるたびに、髪の毛が二重に見えた。すき間は、
   揺れない髪が線なしで埋める。
8. **3x3 の膨張やオープニングを何度も繰り返して、マスクを作らない。** 結果は階段状のひし形になり、
   髪が動くと縁が十字やブロックに見えた。距離変換か、ガウシアンのしきい値を使う。
9. **赤い筋の入った銀髪で壊れた色の決まり。** 髪の色のモデルに赤が含まれるので、
   下絵の赤い襟が髪として通った（首を回すと、あごのそばに赤い斑点）：銀髪では、下絵の塗りは彩度の低い px
   だけを取る（sat < 70）。輪郭線は暗く、「かつ」強い色を持たないもの。

**まばたき**（chara4 と、別のセッションの chara5/chara6。2026-10-23：「目の開閉がずれてます」、
次に「目を瞑る時に目が残っちゃってる」と、その場所を丸で囲んで）。
まばたきは `scripts/motion_strip.py <build> <out> --compare <installed> --blink 1.0` で、見る大きさで1コマずつ確かめ、
閉じた目は拡大して見る：目を閉じたときにまだ残っているものは、すべて間違い。
1. **描いた閉じ線を据える。** Codex は閉じ目を好きな所に描き（chara4 の左目は開口部の上3分の1、
   右目は黒目を横切るまっすぐな斜め線）、まぶたはその線で合わさる：下まぶたが目の半分まで上がった。`eyes.py` の
   seat_closed は、線を列ごとに、目の傾きに沿ったゆるい弧の上へ移す（開口部を上から
   0.88 下がった所の曲線に直線を当てはめ、その反りの 0.4 を残す）。描かれた閉じ目は開いた目より低い位置にあるので、
   目の端は少し下がる。丸い目の下半分の深さをそのまま使うと U 字になり、傾いた目ではチェックマークのような形になった。
2. **上まぶたを2つの縁として扱う**（chara5 のセッションの eye_rig。今は本体のもの）：帯の上端は閉じ線の上端へ、
   まぶたの縁（白目の上端）は閉じ線の下端へ移し、その間の点は帯の中での位置を保つ。白目より外では、
   帯の動く量と厚みを白目の端から引き継ぐので、目の端もまぶたと一緒に下がる。
   帯自身の下端から列ごとに測っていたときは、半分閉じたまつ毛が V 字や Z 字に曲がった。
   まぶたの縁より下のまつ毛（目尻で下へ回り込むもの）は、閉じ線の上に折りたたむ。下まぶたの上がる量は、
   白目の先より外でも保ち、広くならす。そのうち合わさる線より上に来る部分は、その線の上に折りたたむ。
3. **開いた目のものを、顔のレイヤーに何も残さない。** 顔にラベル付けされた絵の目のかけら（白目やハイライトのかけらで、
   肌のように明るいもの）が目を閉じても残り、そのまわりに塗った肌がその明るさを拾った：それぞれの目の、
   つやのある幽霊。今は segment が、目の範囲の中（とそのすぐ外の線の端）の顔を、`face_blank` の下絵から描く。
4. **眉にまつ毛を入れない。** 本物の眉が前髪の下に隠れていると、眉の点がまつ毛の上に来るので、
   まつ毛の上側の線と赤いアクセントが、距離で眉に入った：目を閉じても、それが上に残った。今は segment が、
   目に触れている眉のかけらをすべて目に渡す。今回の実行でレイヤーを作らない段階は、
   古いレイヤーを消す（`layerio.drop_layer`）：古い眉がまだリグに組まれていた。
6. **それぞれの目のマスクは、別に保つ**（`feature_masks.npz` の eye_?_core）：目の窓、輪郭、範囲はそこから取る。
   そこに足したかけら（眉の線、髪の上にかかった目の線）は、分けるときにだけまつ毛に加える。
   それらを目の凸包に入れると、目のまわりの髪が目のレイヤーに入った。足したかけらのどれが髪の輪郭線かは、
   色ではなく `hairmask` の下絵から読む：まつ毛の芯は、髪の輪郭線と同じくらい黒い。髪にラベル付けされた、
   肌の上にある線の端（下絵の肌よりずっと暗く、暖かくはない）も目のもの。build.py では、
   目ごとの曲線をすべて既定引数として束縛する：キーフォームはループのあとで作られるので、
   クロージャだと左目に右目の曲線が渡った（そのまぶたが 10 px 下がった）。
5. **目のレイヤーに髪を入れない**（chara6 のセッションの決まり）：前髪の下では、
   上のまつ毛から髪を写したものを取り除き、下のまつ毛と二重には何も残さない。そして後ろ髪に目を入れない：
   backhair の下絵は目を残しているので、その塗りが白目と赤い線を、この髪の色として取っていた。

**顔の横の横髪：自分の奥行きを持たせ、頭頂からの揺れを減らす**（chara4、2026-10-23）。
- 首を回すと、横髪は隣にある顔の縁の奥行きを取る（build.py の `z_side`。縁から 0.6 HR 外までで弱まって消える）。
  頭の球の奥行きのままでは、10度で顔の縁が35動くところを、横髪は 10〜20 px しか動かず、顔が横髪の下から滑り出た。
- 前髪の頭頂の振り子は、目より下では横髪を3分の1しか揺らさない（`side_damp`）。前髪と同じく頭頂から吊るすと、
  あごまで届く束が 140 px 揺れて頬から離れた：首を回し切って髪が振り出たとき、
  奥の頬に沿って三日月形の背景（すき間チェックの最悪 +822 → +444）。束それぞれの振り子が、横髪を動かし続ける。
  描いた 3/4 の見本の向き絵では、横髪は頬に沿っている。
- `body_top`（髪が体の上に乗る所）は、決してあごより上にしない：体にラベル付けされた帽子、翼、高い襟のせいで、
  髪全体が「乗った」ことになり、頭の首振りの 15 % しか回らなかった（chara5 のセッション）。

## 本体にないもの（これらはテンプレートの手順で、`$P/kit/` かテンプレートの中で作る）

- 描いた色分け図による髪の束には、上の lockmap、sidemap、noside、マスクの下絵が要る（下絵の表にある）。
  それがないと、髪は塊のまま揺れる。
- 自分で揺れる飾り：イヤリング、リボン、マント、尻尾や裾（tails）、翼。
- 切り替え：衣装、目の種類、オン・オフ。
- 腕のポーズ。
- 見本の向き絵（3/4、見上げ、見下ろし）と、それに対する首振りの測定。
- 効果の記号。

本体の髪は、chara2 の振り子で塊ごと（前、後ろ、横）揺れる。首振りとうなずきは chara2 の面で、
正面向きのアニメ顔に合う。
