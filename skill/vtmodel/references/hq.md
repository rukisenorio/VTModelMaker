# 高品質モード（Claude Code ＋ Codex CLI）

画面と `run.py` で作れるのは「最初に動く一体」。高品質モードは、最初のキャラたちを「動く」から「VTube Studio で
崩れない」まで持っていった流れだ。描いた見本、それに合わせた首の回り方、すべての部位を動きで判断すること、前の版と
比べながらの部位ごとの直し。見るのと直すのは Claude、描くのは Codex CLI。

先に `method.md` を読む。`lessons.md` には、これまでに出た崩れと直し方が全部ある。何かが崩れたら、まずそこを検索する。

相手は日本語話者。報告も、確認画像の説明も日本語で。

## 0. 基本の決まり

- 自分の目で見る。確認画像は、作られた大きさで、細部は拡大して全部開く。AI の確認（`hq.py review`）は二つ目の意見で、
  判定ではない。
- 変えるのは一度に一つ。毎回、前の版と動きで比べる。何かが悪くなったら、すぐ戻す。
- キャラのための直しは `<proj>/kit/`（キャラ専用の本体の写し）か `character.json` の設定に入れる。道具の `vtmm/` には
  入れない。
- VTModelMaker 自体を新しくしたあとは、`PY V/update_kit.py <proj>` で写しを最新にする。そのキャラで変えていないファイルは
  入れ替わり、変えたファイルは残って名前が出る（本体の変更が要るなら手で移す）。`--all` は、古い写しを
  `<proj>/backups/` に残してから全部入れ替える。
- 動かして崩れる所が残っているうちは、VTube Studio に入れない。残っている所を、正直に伝える。

## 1. 正しくしておく価値のある入力

1. **原寸の絵。** チャットに貼られた絵は縮んで届く。元のファイルをもらう。
2. **位置合わせ。** `PY V/ai_landmarks.py <proj>` が下書きを作る（Claude、なければ Codex）。そのあと
   `work/ai_points_check.png` と拡大したガイドの絵で全部の点を確かめ、`character.json` を直す。大事なのは目、口、あご、
   顔の輪郭。`crown` は、髪がなければ頭が終わる所。
3. **説明（describe）。** 髪（色、メッシュ、前髪がどこに落ちるか）、目（左右それぞれの色）、頭から足までの服を、
   正確な日本語で。どの下絵の指示にも入る。左右は向かって左右で書く。
4. **下絵は全部、省かない。** `run.py --from plates --to plates` のあと、`work/plates/` の重ねた下絵を一枚ずつ元の絵と
   並べて見る。消しすぎた下絵（残すはずの襟や飾り）や、違うデザインを描いた下絵は消して（`gen/out/<名前>.png` と
   `work/plates/<名前>.png`）、`character.json` → `plates` → `<名前>` → `prompt` にもっとはっきりした指示を書いて
   作り直す（lessons.md: Codex が消してしまう衣装の部分、帽子、襟）。

## 2. 首の回り方と見上げ方を、描いた見本に合わせる

1. `PY V/hq.py <proj> refs` ― Codex が、左右に30度ほど向いた絵と、見上げ・見下ろしを描く（`gen/out/ref_*.png`）。
   それぞれがデザインと構図を保っているか確かめる。悪いものは消して、もう一度。
2. 最初の組み立てのあと: `PY V/hq.py <proj> calibrate --apply` ― `rig.yaw_amp`（首の回り方）と `rig.nod_up_scale`
   （見上げ方）の候補を組み立て、見本を体の位置でそろえて、目の位置を比べる。見本の絵の目の位置は一度だけ測り、候補ごとに
   比べるのはモデルの目（正確に分かる）。候補が見本に届かなければ、安全な範囲（首の回り方 0.5〜2.2、見上げ方 0.5〜3.0）の
   中で候補を足す。目を合わせるだけでは足りない: 首の長い見上げの絵に合わせると、あごの下が裂ける。そこで候補ごとに
   「裂け目」（見本の角度で正面より増える、囲まれたすき間と半透明の量）も測り、いちばん少ない版の1.25倍を超える候補は
   選ばない。見本をはさむ二つの候補がどちらも崩れなければ、その間の値を `character.json` に書いて組み立て直す。崩れる
   ときは、崩れない候補のうち見本にいちばん近い値にする（今の値より見本に近づくときだけ）。理由は
   `preview/hq/calibrate.json` の `notes` と画面に出る。`preview/hq/calibrate.png` を見る: 左がモデル（赤丸が目）、中が
   体の位置でそろえた見本（青丸が目）、右が2枚を半分ずつ重ねた図。各段の見出しに目の差と裂け目の値がある。体の位置が
   合っていない（重ねた図で肩や襟がずれる）なら、測った値は使えない。見本を描き直す。最後は必ず `qa` の nod.png と
   motion.png を、前の版と比べて自分の目で見る（裂け目の値は目安で、判定ではない）。

## 3. くり返し

```
PY V/hq.py <proj> snapshot v1                       # これから変える版を残す
PY V/hq.py <proj> qa --label v2 --compare <proj>/versions/v1
PY V/hq.py <proj> review --label v2                 # 二つ目の意見
```

`preview/qa/<label>/qa.md` に、各画像で見る所が書いてある:

- **motion.png** ― 物理込みの首振り: 髪がほつれる、顔が前髪の下から滑り出る、横髪が頬から離れる、帽子が頭から浮く。
- **blink.png** ― まばたき1回を1コマずつ: 上まぶたが上から下りて、目の下寄りで閉じる。途中でまつ毛の帯がジグザグに
  ならない。閉じた目の上に何も残らない。
- **closed_eyes.png** ― 閉じた目の拡大: 白目、黒目、まつ毛の端、二重の線、髪に透けた線が残っていない。
- **bare.png** ― 揺れる髪（hair_front と lock_*。外した層は図の上に書いてある）を外した状態＝束が揺れたときに見えるもの:
  おでこ、生え際、耳、こめかみが描かれている。四角い穴や灰色の塊がない。揺れない髪（hair_base）は残っていてよい。
- **far_sides.png** ― 首を回し切って髪を振ったとき: 奥の頬の横のすき間、ちぎれた耳、二重になった後ろ髪。
- **nod.png** ― 見上げ・見下ろし: 首の長さ、あごの下の影、帽子と前髪が乗ったままか。
- **mouth.png**、**expressions.png**、**holes.png**（81通りの姿勢でのすき間）、**phys.txt**（物理演算の振れ幅）。

崩れ一つごとに:
1. 誰が描いているかを突き止める: `PY V/preview.py <proj> peel x0,y0,x1,y1 "<姿勢>"` はアートメッシュを一つずつ描く。
2. 教訓を探す: `lessons.md` を部位（目、横髪、生え際、耳、首、襟、帽子…）で検索する。
3. `<proj>/kit/` か `character.json` で直し、その部位の段からやり直す（`run.py <proj> --from <段>`）。
4. 同じ画像をもう一度見て、そのあと残した版とパック全体を比べる。

自分の目でも AI の確認でも、表示サイズで見える崩れがなくなったら終わり。

## 4. 本体が自分では分けない部分

帽子、リボン、鎖、イヤリング、房、コートの裾。自分で揺れるべきもの。うまくいったやり方（lessons.md の
「本体で作ったモデルの第2段階」）: その部分を消す Codex の下絵（「X を消して、後ろにあるものを描いて」）、部分＝絵と下絵が
違う所（ずれに強い差分 `segment.crop_diff`）、後ろのものを下絵から描いた専用のレイヤー、結び目から下がるデフォーマ
（回転デフォーマか、部分に沿って角度が増えるワープデフォーマ）、物理演算の振り子。キャラ専用の段として `<proj>/kit/` に
書き、`<proj>/kit/run.py` の段の並びの `segment` のあとに足す。

## 5. インストールの前に

- パックに表示サイズで見える崩れがない。まばたきが閉じ切る。首の回り方が見本に合っている。
- VTube Studio が閉じている（`platform_env.vts_running()` が False）。そのあと `PY V/package.py <proj> --install`。
- 何を変えたかを伝え、最後の動きの確認画像を見せ、まだ完全でない所を言う。
