# VTModelMaker

キャラクターの絵1枚から、**VTube Studio** で動くモデルを作る道具です。Cubism Editor は使いません。絵をパーツに分け、
絵に描かれていない部分（前髪の下のおでこ、横髪の下の耳、閉じた目など）を画像生成で描き足し、首の向き・うなずき・
まばたき・視線・口・髪の揺れを組んで、`.moc3`・物理演算・表情・VTube Studio の設定まで書き出します。

> **いまの状態**：絵から「最初の一体」を、パソコンの処理時間で1時間ほどで作ります。動かしたときに崩れないかを、
> 道具が作る動きの確認画像で必ず見てください。仕上げには手直し（または下の「高品質モード」）が要る所があります。
> Mac（Apple シリコン）と Steam 版 VTube Studio で作り、確かめています。Windows でも動くように書いてありますが、
> Windows のパソコンではまだ試していません。

## できること

- パーツ：顔、目（白目・黒目・まつ毛・二重）、眉、口、1本ずつ揺れる前髪の束、横髪、後ろ髪、耳、首、体、腕。隠れている
  部分は、ぼかしではなく画像生成で描きます。
- 動き：立体的な頭での首振り・うなずき、傾き、体のひねりと呼吸。描いた閉じ目へのまばたき、笑い目、視線。絵の口の線を
  曲げて作る口（あ・い・う・え・お、歯、舌）。髪や飾りの物理演算。ホットキーで9つの表情。
- VTube Studio の設定：顔のトラッキング（母音も）、ホットキー、待機モーション、アイコン。VTube Studio を閉じている
  ときだけ、モデルのフォルダへ入れます（前に保存された設定は残して足します）。
- 確認：いろいろな向きの一覧、81通りの姿勢でのすき間チェック、物理込みの首振りの並び、まばたきの1コマずつの並び。

## 必要なもの

- macOS 12 以降か Windows 10/11、空き容量 3 GB ほど、インストール時のインターネット。
- **VTube Studio**（Steam）。モデルの確認には、VTube Studio に入っている Live2D Cubism Core を使います（この道具には
  含めていませんし、配布もしません）。
- 下絵（隠れた部分）を描く画像生成：
  - **自動**：ChatGPT のプランでログインした [Codex CLI](https://github.com/openai/codex)
  - **手作業**：ブラウザの ChatGPT。道具が依頼（絵と文章）を用意するので、できた絵を戻します。1キャラで10〜18枚ほど。
    「あるとよい」ものは使わないこともできます。依頼の文章は英語ですが、そのまま貼れば ChatGPT は日本語で返事をします。
- 高品質モードには、さらに Codex CLI と、あれば [Claude Code](https://claude.com/claude-code)（ログイン済み）。

## インストール

1. このリポジトリをダウンロード（Code → Download ZIP）して、置いたままにできる場所（ホームフォルダなど）に展開します。
2. Mac は `install.command`（初回は右クリック →「開く」）、Windows は `install.bat` をダブルクリック。
   フォルダ内の `.venv` に Python 3.12 と必要な部品を入れ（[uv](https://astral.sh/uv) を使います）、
   `~/.vtmm/config.json` を書き、Claude Code 用のスキルを入れて、パソコンに必要なものがそろっているかを確かめます。

## 使い方

**単体で使う**：Mac は `start.command`、Windows は `start.bat` をダブルクリック。ブラウザで画面が開きます。

1. **位置合わせ** ― 絵の上で、目・鼻・口・あご・顔の輪郭・肩など約25か所をクリック（「AIに置いてもらう」もあります）。
2. **説明** ― 髪・目・服をひとことずつ日本語で（空欄でも可。Codex CLI があれば AI が下書きします）。
3. **切り抜き** ― キャラを切り抜きます。腕と体のすき間など、囲まれた背景にチェック。
4. **下絵** ― 自動で描くか、手作業モードなら ChatGPT で1枚ずつ。
5. **組み立て** ― モデルを組み立てます（10〜30分）。
6. **確認・インストール** ― 動きの確認画像を見て、VTube Studio に入れます。

**Claude Code に頼む**：絵を渡して「この絵をVTube Studioのモデルにして」と頼みます。スキル（`skill/vtmodel`）が同じ手順を
進め、位置合わせも自分でやり、仕上げ（どのパーツが崩れているかを調べて直し、前の版と動きで比べる）まで続けられます。
画面で始めたキャラを Claude で仕上げることも、その逆もできます。

## 高品質モード（Claude Code ＋ Codex CLI）

上の手順で作れるのは「最初の一体」です。高品質モードは、それを VTube Studio で崩れないところまで持っていく流れです。
Codex CLI が絵を描き、Claude Code が絵を見て確かめます（Claude Code がない、またはログインしていないときは Codex が
見ます）。

- **AI で位置合わせ** ― Claude（なければ Codex）が約25か所の点を置きます。画面で確かめて直します。
- **見本の向き絵** ― Codex が同じキャラを、左右に30度向いた絵・見上げ・見下ろしで描きます。
- **首の回り方・見上げ方を見本に合わせる** ― 回り方と見上げ方の候補を何通りか組み立て、見本の絵を体の位置でそろえて、
  目の位置を比べます。見本に届かなければ候補を足して試します。候補ごとに「裂け目」（その角度で出るすき間や半透明の量）も
  測り、崩れる候補は選びません。見本どおりにすると崩れるとき（見本の絵が大げさなときによくあります）は、崩れない範囲で
  見本にいちばん近い値にして、理由を画面に出します。
- **確認パック** ― 物理込みの首振り（残した版と比べる）、まばたき1コマずつ、閉じた目、揺れる髪を外した状態、首を
  回し切って髪を振ったとき、見上げ・見下ろし、母音、表情、すき間、揺れの量。
- **AI の確認** ― Claude（なければ Codex）が確認パックを全部見て、どこがどれくらい崩れているかを日本語でまとめます。
  これは二つ目の意見です。最後は自分の目で、動かして確かめてください。
- **版を残す** ― 作った版を残し、次の版と比べます。

画面では「7. 高品質」のボタンです。Claude Code なら「VTModelMaker の <名前> を高品質で仕上げて」と頼むと、同じ道具を
使ったうえで、確認パックで見つかった所を部位ごとに直し、直すたびに残した版と動きで比べます
（`skill/vtmodel/references/hq.md`）。コマンドでは `python vtmm/hq.py <プロジェクト> refs | calibrate --apply | qa | review | snapshot`
と `python vtmm/ai_landmarks.py <プロジェクト>`。

Claude Code に確認してもらうには、ターミナルで一度 `claude` を起動して `/login` でログインしておいてください。

## キャラごとの本体の写し

キャラごとに本体の写し（`projects/<名前>/kit/`）を持つので、あるキャラのための直しがほかのキャラを変えることはありません。
VTModelMaker を新しくしたら、`python vtmm/update_kit.py <プロジェクト>`（画面では「7. 高品質」→「このキャラの本体を最新にする」）で
キャラの写しを最新にします。そのキャラのために直したファイルは残して、名前を出します。

## しくみ

```
絵 ─ setup ─ prep（キャンバス・切り抜き）─ plates（画像生成：「〇〇を消した絵」・色分け図）
   ─ segment（パーツと隠れた部分）─ hair_base ─ locks ─ eyes ─ face_parts（眉・口）
   ─ build（デフォーマ・キーフォーム・物理 → .moc3）─ package（VTube Studio の設定・インストール）─ preview
```

- `vtmm/` ― 本体。`vtmm/l2d/` が、手続きで組んだリグから `.moc3`（moc バージョン3、Cubism 4.0 の形式）を書きます。
  ワープと回転のデフォーマ（キーフォームは Python の関数から取る）、レイヤーからのメッシュ、マスク、パーツ、
  physics3、表情、cdi3。詳しくは `docs/engine.md`。
- `vtmm/app/` ― 画面（Python の標準ライブラリと素の JavaScript）。
- `skill/vtmodel/` ― Claude Code 用スキル。`references/method.md`（作り方の9つの決まり）、`references/lessons.md`
  （これまでに出た崩れと直し方の全部）、`references/hq.md`（高品質モードの進め方）。
- `projects/<名前>/` ― キャラごとのフォルダ（絵、下絵、レイヤー、モデルは `out/<名前>/`）。
- `tests/` ― `python -X utf8 tests/test_moc3.py`（.moc3 の書き出しと読み戻し）、`tests/test_update_kit.py`。

`~/.vtmm/config.json` の設定（どれも省略可）：`imagegen`（`codex` か `manual`）、`vts_dir`、`vts_models_dir`、
`core_lib`（VTube Studio のものではなく公式 SDK の Cubism Core を使うとき）、`codex`、`font`、`projects_dir`。

## 絵・AI・権利

使う権利のある絵だけを使ってください。隠れた部分は画像生成で描きます。モデルを公開・販売するときは、販売先の決まり
（AI 使用の表示など）に従ってください。作ったモデルはあなたのものです。

## Live2D について

VTModelMaker は独立したプロジェクトで、株式会社Live2D とは関係がなく、同社の承認を受けたものでもありません。
「Live2D」「Cubism」は株式会社Live2D の商標です。Live2D Cubism Core はこのリポジトリに含まれていません。VTube Studio と
一緒に入っているもの（または指定したもの）を、Live2D 社のライセンスのもとで読み込んで使います。
